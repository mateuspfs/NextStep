Definição de Stacks e arquitetura base:

Back\-end e Banco de Dados:

Será feito em formato de API com as linguagens C\# e MySQL\.

Frontend: 

Será utilizado React e Tailwind CSS com algumas partes em TypeScript como linguagem principal\.

O objetivo é fazer uma aplicação externa de back\-end e banco de dados para que seja consumido em formato de API para a view do Front\-end, focado em uma estrutura separada em Cloud que funcione em conjunto e seja altamente acoplável e escalada\.

A arquitetura será dividida em dois repositórios utilizando a ferramenta Git/Github para o versionamento\.

IDE para desenvolvimento: VS code

Ordem do desenvolvimento \(funcionalidades\):  
  
*Lógica de contas \(Autenticação de usuários\):*

Como objetivo de prioridade inicial, foi definido a necessidade do funcionamento do login/autenticação do usuário adm na qual irá visualizar determinadas telas como medida de teste e o módulo cadastro/consulta/alteração/exclusão do usuário comum que será feito pelo adm dentro do sistema\.

Abaixo segue as demais definidas em ordem:

\- Central de processos

\- Base de conhecimento

\- Painel de atividades

\- Gameficação

\- Dashboard

Modelo de organização para desenvolvimento:

A fim de organizar o desenvolvimento e atuação geral no projeto, foi definido uma regra para documentação e atribuição de tarefas através do painel de gestão com o Microsoft Planner \(link na central de pré\-documentação\)\.

Durante o desenvolvimento, as funcionalidades serão transformadas em tags aplicáveis para que possam ser inseridas nas tarefas do Planner com as etapas de implementação para determinado requisito da ferramenta em si, permitindo assim uma identificação mais clara do desenvolvimento junto de uma quebra do todo que envolve a funcionalidade\.

Ademais, é importante lembrar que todo o desenvolvimento será baseado em Sprints para controlarmos o tempo em horas \(a definir\) em relação a expectativa de entrega e mitigação de riscos que podem ocorrer ao longo do projeto\.
